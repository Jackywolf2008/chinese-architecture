# 阅读器

应县木塔和悬空寺共用这一套外壳。第三本书（例如佛光寺东大殿）只准备自己的模型、正文，和少量钩子。

`src/engine.js` 负责外壳、翻页、镜头、导览、重建、墨线、点选和标注。`src/shell.css` 是纸面。`build.mjs` 把一本书的 `src/main.js` 打进 `docs/<书名>/app.js`。

## 两本书原来差在哪里

外壳是同一套：后退、前进、封面、面包屑、目录、红点、字幕导览、逐步重建、剖开 / 透视 / 分层 / 旋转、纸墨配色、非阻塞的网页字体、暗色、减少动效、窄屏。页面字段也一样：`say`、`lead`、`facts`、`tl`、`hot`、`links`、`cam`、`acts`、`st`。

真正分开的是模型和这些旋钮：

| | 应县木塔 | 悬空寺 |
| --- | --- | --- |
| 镜头 | 宽高换算距离，视场 34° | 直接给距离，视场 36° |
| 开场 | 先拉远再落到封面 | 直接用封面机位 |
| 墨线 | 连地面也描，切面参与法线 | 崖壁、树、水不描线 |
| 阴影 | 明确用 PCF，颜色按线性光 | 原来写了已删除的 PCFSoft，运行时退回 PCF |
| 工具 | 剖开、透视、分层、地震 | 剖开、透视、分层、摇一摇 |
| 分层 | 拉开时改机位 | 机位不动 |
| 重建 | 塑像那几步保持剖开；离开建造页不把已盖的步重播 | 离开建造页从头落一次；减少动效时直接跳完 |
| 导览 | 句间再停 400 毫秒，回到这一页会重播镜头 | 句间不额外停，暂停后续播不重取镜头 |
| 事实栏 | 数字 20px、不换行；时间轴年份 16px | 数字 18px；时间轴年份 15px |
| 正文图 | 有照片 | 没有 |

这些数字留在各书的 `main.js` 和 `stage.js` 里，不并成一种样子。

## 书要提供什么

`boot(book)` 的 `book`：

- `pages`、`cams`、`tourRoute`：正文、机位、导览路线。机位可以是 `{t, r, th, ph}`，也可以是 `{t, w, h, th, ph}`，由阅读器按当前画幅换算距离。依赖几何的机位用字符串名字，`createStage` 返回的 `cams` 会补进去。
- `createStage(ctx)`：`ctx` 里有 `THREE`、`scene`、`camera`、`renderer`、`reduced`、`fast`、`mobile`。返回 `steps`，以及 `apply`、`scalars`、`mats`、`place`、`pickables`、`acceptHit`、`onPick`、`onHover`、`labelPoint`、`inkHide`。可选 `syncBuild`、`prepareLabels`、`filterLabels`、`onNavigate`、`buildCam`、`inkPlanes`、`cams`，和 `spin`（当前转速）。
- `build`：建造页的导语、空场短句、每步卡片、镜头、播放间隔。`state(bk, steps)` 在建造时覆盖剖开、旋转这些开关。
- `tour`：字幕停留、进页停顿、建造过程的两句开场和收束、每步怎么念。
- 其余是旋钮：曝光、像素比、视场、手势范围、墨线颜色和阈值、工具列表、旋转延迟。

`steps[i]` 至少要有 `name`、`group`。木塔的工序说明还用 `level`、`tag`、`top`、`text`。

## 行为取舍

两边原来不一样、现在收成一种的地方：

1. 阴影都明确用 `PCFShadowMap`。three.js 0.186 已经删了 `PCFSoftShadowMap`，悬空寺原来那一行只会警告并退回 PCF。阴影改为手动更新，颜色通道画之前刷新一次，抓帧可以关掉。
2. `?fast` 和“减少动效”的镜头直接到位，不再做 10 毫秒过渡。无头 Chrome 里帧时间戳会比 `performance.now()` 慢，短过渡的缓动参数会变成负数，半径变成 NaN，墨线通道里 `NaN.toArray` 抛一次；补帧时两帧时间戳还可能相同，缓动停在起点，实验室页面看起来是空的。正常翻页仍做缓动：起点用这一帧的 `requestAnimationFrame` 时间戳，缓动参数限制在 0 到 1，矩阵不是有限数就不上传。
3. 两本书都用 `replaceState` 写地址哈希，方便把当前页分享出去。木塔原来只读不写。打开时的第一页记进浏览历史，后退才能回到封面。悬空寺原来第一页不入历史，点进内页之后后退一直是灰的。封面按钮的 id 不用 `home`，换哈希时也不滚动页面，避免 `#home` 被当成页内锚点把顶栏卷走。
4. 页面藏到后台时，镜头还在动、建造还在播、导览还在讲，就继续画。木塔原来一隐藏就停。
5. 按钮都带 `type="button"`。导览按钮有 `aria-label`。
6. 地址上的 `?noink` 两本书都认。木塔原来没有这个开关。
7. 点选悬停：木塔仍按 60 毫秒节流更新提示；指针离开构件时马上去掉高亮，避免粘住。

讲解文字没有改。木塔依赖几何的两个机位（斗拱、屋角）改成名字 `dou1Cam`、`cornerCam`，句子本身不动。
